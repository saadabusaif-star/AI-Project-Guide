③ How to build – choose one path

Every path needs: the school header at the top, your names in the footer, and an AI prompt log.

Path A – Python website + NVIDIA AI (looks like a mobile app)
  1. Create a free account on PythonAnywhere → Web → Add a new web app → Flask.
  2. Get a free API key on build.nvidia.com. Keep it in a separate file – never in your page.
  3. Ask Z.ai / ChatGPT / Claude to write ONE part at a time: the page, then the /api route that calls the NVIDIA model.
  4. Write a good system prompt – this is how you teach the AI its job (language, facts, personality).
  5. Make it look like a phone app: big buttons, one column, school header at the top.
  6. Press Reload on the Web tab after every change. Test on your phone.
Path C – Telegram AI bot
  1. Open @BotFather → /newbot → copy the token (keep it secret).
  2. Plan the conversation: buttons and questions the bot asks.
  3. Ask an AI to help you write the bot in Python; connect an AI model for smart answers.
  4. Run it on PythonAnywhere and test with friends in a TEST group.
Path B – AI app makers (no server needed)
  1. Describe your app in clear words to Base44, Lovable or Bolt.new (your teacher helps with accounts).
  2. Ask for the school header at the top and your names in the footer.
  3. Improve it with short follow-up prompts – one change at a time. Log each prompt.
  4. Publish (or export and drop the folder on Netlify Drop) and test the link on a phone.
Path D – Teachable Machine inside a web app
  1. Train an image, sound or pose model on Teachable Machine (30+ samples per class).
  2. Export → Upload my model → copy the link.
  3. Build a page around it (Path A or B) that does something useful with the result.
🔐 Never put API keys or bot tokens in a page, screenshot or video. Use FAKE names when testing – no real personal data.
