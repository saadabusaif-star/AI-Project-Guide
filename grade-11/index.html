③ Know your parts

What each part does, how it connects, and a link to learn more.

Arduino UNO R3The brain. Runs your code; 14 digital pins (D0–D13) and 6 analog inputs (A0–A5).
🔌 USB to laptop • 5V and GND to the breadboard rails
💡 Never use D0/D1 – they are the USB serial line.
🔗 Arduino UNO docs
BreadboardJoins parts without soldering. Each row of 5 holes is connected; the long side rails carry 5V (+) and GND (−).
🔌 Arduino 5V → red rail • GND → blue rail
💡 Buttons and chips must straddle the centre gap.
🔗 How to use a breadboard
LEDA small light – ON or OFF from a digital pin.
🔌 Long leg (+) → 220Ω → pin • short leg (−) → GND
💡 No resistor = burnt LED. Backwards = no light.
🔗 Blink example
RGB LEDThree LEDs (red, green, blue) in one – mix them to make any colour.
🔌 R, G, B legs → 220Ω → pins • longest leg → GND
💡 Colours wrong? It may be common ANODE (longest leg to 5V).
🔗 RGB LED lesson (Adafruit)
ResistorsLimit current. 220Ω (red-red-brown) protects LEDs; 10kΩ (brown-black-orange) makes dividers for LDR / thermistor.
🔌 In series with an LED, or from the analog pin to GND in a divider
💡 Read the colour bands before you use one.
🔗 Resistors & colour code
Push buttonLets the user tell the program something.
🔌 One leg → pin (INPUT_PULLUP) • opposite leg → GND
💡 Pressed = LOW. Straddle the centre gap.
🔗 Button example
Potentiometer (knob)A knob that gives a value 0–1023 – used to set a level.
🔌 Outer legs → 5V and GND • middle leg → analog pin
💡 If it works backwards, swap the outer legs.
🔗 AnalogReadSerial example
Active buzzerMakes one fixed beep when the pin is HIGH.
🔌 + (long leg) → pin • − → GND
💡 It cannot play notes – that needs the passive buzzer.
🔗 Buzzer tone example
Passive buzzerPlays any note with tone(pin, frequency).
🔌 + → pin • − → GND
💡 Only clicks? You picked the ACTIVE one.
🔗 toneMelody example
7-segment displayShows one number 0–9 using 7 small LED bars (a–g).
🔌 a–g → D2–D8 each through 220Ω • COM → GND
💡 Nothing lights? It may be common ANODE (COM → 5V).
🔗 7-segment display (Wikipedia)
DHT11 temperature & humidityDigital sensor: temperature (0–50 °C) and humidity (20–90 %).
🔌 VCC → 5V • DATA → pin • GND → GND
💡 Needs the Adafruit DHT library; read every 2 s.
🔗 DHT11 guide (Adafruit)
Photoresistor (LDR)Resistance drops when light rises – measures brightness.
🔌 One leg → 5V • other leg → analog pin + 10kΩ to GND
💡 Lights flicker – average several readings.
🔗 Photocells (Adafruit)
Thermistor (NTC 10k)Resistance drops when it gets hotter – measures temperature.
🔌 One leg → 5V • other leg → A0 + 10kΩ to GND
💡 Use the Beta formula in the code, not map().
🔗 Thermistor guide (Adafruit)
Tilt / vibration switchA small ball inside closes the contact when it is tipped or shaken.
🔌 One leg → pin (INPUT_PULLUP) • other leg → GND
💡 It bounces – the code waits a short time to be sure.
🔗 Tilt sensor (Adafruit)
IR obstacle moduleSends infrared light and sees it bounce back – detects something close.
🔌 VCC → 5V • GND → GND • OUT → pin (LOW = close)
💡 Turn the blue screw to set the distance. Fails on black or glass.
🔗 Proximity sensors (Wikipedia)
Sound sensor moduleA microphone – AO gives the live sound wave, DO gives loud/quiet.
🔌 VCC → 5V • GND → GND • AO → A0
💡 Use AO for loudness; the screw only changes DO.
🔗 Microphone (Wikipedia)
Soil moisture probe + moduleMeasures how well soil or water conducts – wetter or saltier = different reading.
🔌 VCC → 5V • GND → GND • AO → A0
💡 The probe corrodes – lift it out between tests.
🔗 Soil moisture sensor (Wikipedia)
Water level sensorMore water on the strips = higher reading.
🔌 + → D7 (power only while reading) • − → GND • S → A0
💡 Switch it off between readings to stop corrosion.
🔗 Level sensor (Wikipedia)
Jumper wiresCarry power and signals between the board and the parts.
🔌 Male-male for the breadboard • male-female for sensor modules
💡 Use red for 5V and black for GND – easier to check.
🔗 Breadboard & wires guide

⑤ If something goes wrong

Tap a problem to see the fix. Your project page also lists the problems for your project.

⚡ Power & upload

The green ON light does not come on

Unplug at once – there is a short circuit. Look for a wire joining 5V and GND, or a module plugged in backwards.

Upload fails / “port not found”

Tools › Board › Arduino Uno, then Tools › Port – pick the COM port that appears when you plug in. Close the Serial Monitor. Try another USB cable or laptop port.

“avrdude: stk500 not in sync”

Something is plugged into D0 or D1 – move it. Press the reset button just before Upload.

Code uploads but nothing happens

Check the wires go to the SAME pin numbers as the const lines at the top of the code.

💡 LEDs, RGB and 7-segment

An LED never lights

Long leg to the resistor/pin, short leg to GND. Test the LED with the Blink example on that pin.

Only some LEDs light

Each LED needs its OWN 220Ω resistor – do not share one.

RGB shows the wrong colours

It is common ANODE: longest leg to 5V and set RGB_COMMON_ANODE = true.

7-segment is dark

Common ANODE display: COM to 5V and set SEG_COMMON_ANODE = true. Check COM is really connected.

7-segment shows strange shapes

One segment wire is in the wrong pin. Compare a→D2 … g→D8 with the pinout picture.

🔘 Buttons, knobs and switches

Button does nothing

It must straddle the centre gap. Use two legs on OPPOSITE sides of the gap.

One press counts many times

Contact bounce – the code’s justPressed() handles it. Make sure you didn’t delete it.

Knob works backwards

Swap the two outer legs (5V and GND).

Tilt switch triggers by itself

Its resting position is closed. Turn it so it is OPEN when the device is normal.

🌡️ Sensors

DHT11 prints “nan”

Install “DHT sensor library” + “Adafruit Unified Sensor”. Check DATA pin. Add a 10k from DATA to 5V. Wait 2 s between reads.

LDR / thermistor value barely changes

The 10kΩ must go from the analog pin to GND, and the sensor from 5V to the same row.

Thermistor shows −273 or a huge number

The divider is reversed: thermistor to 5V, 10k to GND.

Sound score stuck at 0 or 9

Change QUIET_PP / LOUD_PP using the numbers you see in the Serial Monitor.

IR sensor always “close”

Turn the blue screw back. Avoid sunlight. It does not see black or glass well.

Soil / salt readings jump

Push the probe to the same depth every time; dry and clean it between cups.

🔊 Buzzers

Buzzer only clicks

tone() needs the PASSIVE buzzer. The active one just beeps on HIGH.

Buzzer never stops

Check the condition in the code and that the buzzer + is on the right pin.

PWM colour stops when the buzzer plays

tone() uses the timer of pins 3 and 11 – use 5, 6 or 9 for PWM.

💻 Serial Monitor & Tinkercad

Serial Monitor shows strange symbols

Set the speed to 9600 baud (bottom-right of the Serial Monitor).

Serial Plotter is one flat line

Print numbers only, separated by commas – no words.

Part missing in Tinkercad

Use the substitute on your sheet (e.g. TMP36 for DHT11, button for IR module).

Tinkercad code error

Tinkercad has no DHT library – use the T1 snippet from your sheet in Tinkercad only.

⚡ Safety: build with USB unplugged • every LED needs 220Ω • never swap 5V and GND • if the board gets hot, unplug at once.
