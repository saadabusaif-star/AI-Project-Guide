Hot Car Child Alarm

Detects an occupied seat in a parked car and alarms before the cabin turns dangerous

MediumTilt + DHT11⏰ Due Friday 30 October
PurposePartsWiringCodeBuild & testAI promptsProblemsPoster & videoFiles

🎯 Purpose

What it does: A switch under the seat cushion shows the seat is occupied. The DHT11 watches cabin temperature. If the seat is occupied AND the cabin passes the danger temperature, the RGB flashes red and the buzzer sounds continuously. A button arms and disarms it when the driver returns.

🇦🇪 UAE link: Children left in parked cars — a recurring UAE summer tragedy

Why it matters: A car parked in Gulf sunshine can pass 60 degrees inside in under twenty minutes, and children die this way in the UAE almost every summer. The parent is never careless on purpose — the failure is memory, and memory is exactly what a machine is good at. The AND condition is the entire design: alarm only when the seat is occupied and it is hot. An empty parked car that screams all afternoon gets disconnected within a week, and then it saves nobody.

Who it helps: Parents of young children — and every driver who has ever left a car in the summer sun.

/* PROJECT 10 - HOT CAR CHILD ALARM  (11.C Group 5)
   Alarm ONLY when the seat is occupied AND the car is too hot.
   RGB: GREEN empty, YELLOW occupied & OK, flashing RED + buzzer = danger,
   BLUE = system disarmed (ARM button toggles).                         */
#include <DHT.h>
#define DHTPIN  3
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);

const int SEAT = 2;                     // tilt switch as seat sensor (LOW = occupied)
const int BUZZ = 4;                     // ACTIVE buzzer
const int ARM  = 5;                     // ARM / DISARM button
const int R = 9, G = 10, B = 11;        // RGB LED (each through 220 ohm)
const float TEMP_LIMIT = 32.0;          // 32 for the class demo, about 30 in a real car

bool armed = true;
int  lastBtn = HIGH;
float t = NAN;
unsigned long lastRead = 0;

// ---------- RGB LED ----------
const bool RGB_COMMON_ANODE = false;   // true = longest leg goes to 5V instead of GND
void colour(bool r, bool g, bool b) {
  digitalWrite(R, RGB_COMMON_ANODE ? !r : r);
  digitalWrite(G, RGB_COMMON_ANODE ? !g : g);
  digitalWrite(B, RGB_COMMON_ANODE ? !b : b);
}
// True ONCE at the moment a button goes from up (HIGH) to pressed (LOW).
// Holding the button down does NOT repeat it.
bool justPressed(int pin, int &lastState) {
  int now = digitalRead(pin);
  bool pressed = (lastState == HIGH && now == LOW);
  lastState = now;
  if (pressed) delay(25);               // ignore contact bounce
  return pressed;
}

void setup() {
  Serial.begin(9600);
  dht.begin();
  pinMode(SEAT, INPUT_PULLUP);
  pinMode(ARM, INPUT_PULLUP);
  pinMode(BUZZ, OUTPUT);
  pinMode(R, OUTPUT); pinMode(G, OUTPUT); pinMode(B, OUTPUT);
}

void loop() {
  if (justPressed(ARM, lastBtn)) { armed = !armed; Serial.println(armed ? "ARMED" : "DISARMED"); }

  if (millis() - lastRead >= 2000) {    // DHT11 every 2 s
    lastRead = millis();
    float v = dht.readTemperature();
    if (!isnan(v)) t = v;
    Serial.print("occupied="); Serial.print(digitalRead(SEAT) == LOW);
    Serial.print("  T="); Serial.println(t);
  }

  if (!armed) { colour(0, 0, 1); digitalWrite(BUZZ, LOW); return; }

  bool occupied = (digitalRead(SEAT) == LOW);
  bool danger = occupied && !isnan(t) && t > TEMP_LIMIT;   // the AND is the whole idea

  if (danger) {
    bool flashOn = (millis() / 300) % 2;                    // flash every 300 ms
    colour(flashOn, 0, 0);
    digitalWrite(BUZZ, flashOn);
  } else {
    digitalWrite(BUZZ, LOW);
    if (occupied) colour(1, 1, 0);      // yellow
    else          colour(0, 1, 0);      // green
  }
}

🛠️ Build & test

Build order
  1. Arduino 5V → red rail, GND → blue rail.
  2. Wire the tilt switch and print its state. Tape it under a folded cloth so pressing tips it.
  3. Add the DHT11 and confirm the temperature reading.
  4. Add the RGB LED and buzzer.
  5. Set the limit to 32 for the classroom; explain that a real unit uses 30.
  6. Partner checks every wire, THEN plug in USB.
  7. Upload and open Serial Monitor (9600).
Test & record (your evidence)
  • Occupied plus a cool room MUST stay quiet — this proves you did not just build a thermometer alarm.
  • Occupied plus warm hands on the sensor: alarm within seconds.
  • Empty seat plus a hot sensor MUST stay quiet.
Tinkercad first
  • DHT11 → not in Tinkercad: use a TMP36 temperature sensor on A2 + a potentiometer on A3 as 'humidity' (snippet T1).
  • Active buzzer → use an LED + 220Ω in its place so you can SEE every beep (no code change).
  • Tilt switch → use Tinkercad's Tilt Sensor, or a Pushbutton/Slideswitch to fake a tilt.
  • RGB LED → 'LED RGB', set it to Cathode in the inspector.

🆘 Problems in this project

Seat always reads occupied

the ball rests closed. Mount it so the resting state is OPEN.

Alarm fires on an empty seat

you used OR instead of AND.

Temperature climbs too slowly for the booth

hold the DHT11 in your fist or drop the limit to 30.

Button does nothing

it is not straddling the centre gap, or both wires are on legs that are already joined. Use legs on OPPOSITE sides of the gap.

More fixes: all troubleshooting.
