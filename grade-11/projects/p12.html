Al Zorah Mangrove Tide Monitor

Watches the tide over a mangrove nursery and warns when seedlings dry out

EasyWater level⏰ Due Friday 30 October
PurposePartsWiringCodeBuild & testAI promptsProblemsPoster & videoFiles

🎯 Purpose

What it does: A level sensor in the water shows the tide as three stages: low, mid and high. A tilt switch detects that the marker stake has been knocked over. The buzzer warns if the water stays too low for too long, or if the stake has fallen. The sensor is powered from an Arduino pin and switched on only for the 20 ms of the reading.

🇦🇪 UAE link: Al Zorah, Ajman — mangrove and flamingo habitat on our own doorstep

Why it matters: Al Zorah in Ajman holds one of the most important mangrove and flamingo habitats in the country, and mangroves are among the strongest natural carbon stores on this coast. Young seedlings need regular tidal flooding — too little and they dry out, too much and they drown. Volunteer replanting groups cannot stand in the creek all day watching the water. The engineering decision here is the one judges will ask about: a permanently powered water sensor corrodes its own traces within days, so you power it only for the instant you read it.

Who it helps: Mangrove nurseries, environmental rangers and researchers along the Ajman / Al Zorah coast.

/* PROJECT 12 - AL ZORAH MANGROVE TIDE MONITOR  (11.C Group 7)
   Water level sensor -> RED low tide, YELLOW mid, GREEN high tide.
   Low tide OR the stake falling over (tilt switch) -> beep.
   The sensor is powered from D7 ONLY while reading = much less corrosion. */
const int SENSE = A0, POWER = 7;
const int RED = 2, YEL = 3, GRN = 4;    // LEDs (each through 220 ohm)
const int TILT = 5;                     // tilt switch on the stake
const int BUZZ = 6;                     // ACTIVE buzzer

// ---- CALIBRATE with your own cup of water ----
const int LOW_MARK = 150, HIGH_MARK = 400;

unsigned long tiltSince = 0, lastBeep = 0, lastRead = 0, lastPrint = 0;
int lvl = 0;

int readLevel() {
  digitalWrite(POWER, HIGH);            // switch the strip ON
  delay(20);
  int v = analogRead(SENSE);
  digitalWrite(POWER, LOW);             // and OFF again
  return v;
}

void setup() {
  Serial.begin(9600);
  pinMode(POWER, OUTPUT); digitalWrite(POWER, LOW);
  pinMode(RED, OUTPUT); pinMode(YEL, OUTPUT); pinMode(GRN, OUTPUT);
  pinMode(BUZZ, OUTPUT);
  pinMode(TILT, INPUT_PULLUP);
}

void loop() {
  if (millis() - lastRead >= 400) { lastRead = millis(); lvl = readLevel(); }

  // stake counts as fallen only if the tilt switch stays closed for 300 ms
  if (digitalRead(TILT) == LOW) { if (tiltSince == 0) tiltSince = millis(); }
  else tiltSince = 0;
  bool fallen = (tiltSince != 0 && millis() - tiltSince > 300);

  digitalWrite(RED, lvl <  LOW_MARK);
  digitalWrite(YEL, lvl >= LOW_MARK && lvl < HIGH_MARK);
  digitalWrite(GRN, lvl >= HIGH_MARK);

  bool alarm = (lvl < LOW_MARK) || fallen;
  if (alarm && millis() - lastBeep >= 1000) lastBeep = millis();
  digitalWrite(BUZZ, (alarm && millis() - lastBeep < 120) ? HIGH : LOW);

  if (millis() - lastPrint >= 1000) {
    lastPrint = millis();
    Serial.print("tide="); Serial.print(lvl);
    Serial.print("  stake fallen="); Serial.println(fallen);
  }
}

🛠️ Build & test

Build order
  1. Arduino 5V → red rail, GND → blue rail.
  2. Build the three LEDs first and flash them in sequence to prove all three pins work.
  3. Wire the sensor + to D7, not to 5V. Explain to your teacher why before continuing.
  4. Add the tilt switch and print its state while you rock the board.
  5. Add the buzzer and calibrate the tide thresholds with a real cup of water.
  6. Partner checks every wire, THEN plug in USB.
  7. Upload and open Serial Monitor (9600).
Test & record (your evidence)
  • Record the dry reading, then at 1 cm, 2 cm and 3 cm. These set your thresholds.
  • Tip the board with the water high — the buzzer must sound even though the level is fine.
  • Run it 10 minutes and check the traces are not bubbling — proof the pin-power trick works.
Tinkercad first
  • Water level sensor → use a Potentiometer: outer legs to D7 and GND, middle leg to A0.
  • Active buzzer → use an LED + 220Ω in its place so you can SEE every beep (no code change).
  • Tilt switch → use Tinkercad's Tilt Sensor, or a Pushbutton/Slideswitch to fake a tilt.

🆘 Problems in this project

Reading always 0

you forgot pinMode(POWER, OUTPUT).

Only one LED works

you shared a resistor. Each LED needs its own 220Ω.

Tilt switch chatters

it is a rolling ball. Require LOW for 100 ms before alarming.
