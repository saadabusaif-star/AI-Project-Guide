Masjid Corridor Light Saver

Light only when it is dark AND somebody is actually there

MediumLDR + IR⏰ Due Friday 30 October
PurposePartsWiringCodeBuild & testAI promptsProblemsPoster & videoFiles

🎯 Purpose

What it does: A light sensor decides whether it is dark. An infrared sensor decides whether someone is passing. The lamp — four LEDs — turns on only when BOTH are true, and stays on ten seconds after the person leaves. A knob sets how dark is dark, so one unit suits a bright lobby or a dim stairwell.

🇦🇪 UAE link: Energy waste in mosques, majlis entrances and villa stairwells

Why it matters: Mosque corridors, wudu areas, majlis entrances and villa stairwells across the country stay lit all night for nobody. A timer switch is worse than useless — it runs in daylight too. The design idea is two conditions joined by AND, which is exactly how commercial occupancy sensors work. The ten-second hold is not decoration: without it the light drops out while you are still walking, and people tear the sensor off the wall.

Who it helps: Mosque and community-building managers who want to cut wasted electricity (UAE Net Zero 2050).

/* PROJECT 6 - MASJID CORRIDOR LIGHT SAVER  (11.B Group 6)
   Lamps (4 LEDs) switch on ONLY when it is dark AND a person passed in
   the last 10 seconds. The knob sets how dark counts as "dark".         */
const int LDR = A0, KNOB = A1;
const int IR = 2;                       // IR OUT (LOW = person)
const int LAMP[4] = {3, 4, 5, 6};       // 4 LEDs, each with its OWN 220 ohm
const unsigned long HOLD_MS = 10000;    // lamps stay on 10 s after last person

unsigned long lastSeen = 0;
bool everSeen = false;

void setup() {
  Serial.begin(9600);
  pinMode(IR, INPUT);
  for (int i = 0; i < 4; i++) pinMode(LAMP[i], OUTPUT);
}

void loop() {
  int light     = analogRead(LDR);                       // brighter = bigger
  int darkLevel = map(analogRead(KNOB), 0, 1023, 100, 900);

  bool isDark = (light < darkLevel);
  bool person = (digitalRead(IR) == LOW);
  if (person) { lastSeen = millis(); everSeen = true; }

  bool on = isDark && everSeen && (millis() - lastSeen < HOLD_MS);
  for (int i = 0; i < 4; i++) digitalWrite(LAMP[i], on);

  // three numbers -> open Tools > Serial Plotter to see the graph
  Serial.print(light);     Serial.print(",");
  Serial.print(darkLevel); Serial.print(",");
  Serial.println(on ? 900 : 0);
  delay(100);
}

Arduino IDE: save it inside a folder with the same name (P06_Masjid-Corridor-Light-Saver). Tools › Board › Arduino Uno → Port → Upload → Serial Monitor 9600.

🛠️ Build & test

Build order
  1. Arduino 5V → red rail, GND → blue rail.
  2. Build the LDR divider and print analogRead(A0). Record the value covered and in torchlight.
  3. Add the knob and confirm it sweeps 0 to 1023.
  4. Add the IR module and check it sees a hand at 15 cm.
  5. Add the four LEDs and write the AND logic with the 10-second hold.
  6. Partner checks every wire, THEN plug in USB.
  7. Upload and open Serial Monitor (9600).
Test & record (your evidence)
  • Room light plus a waving hand: lamp must stay OFF.
  • Cover the LDR then wave: lamp must come ON.
  • Cover it and stand still 15 s: lamp must switch itself OFF.
Tinkercad first
  • IR obstacle module → use a Pushbutton (pressed = LOW = 'something close'), same pin.
